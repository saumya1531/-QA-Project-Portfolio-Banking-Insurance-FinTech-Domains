# Defect Management

This folder contains sample defect management artifacts for the Banking, Insurance and FinTech QA portfolio.

## Defect Lifecycle

- Defect identification
- Defect logging
- Defect triage
- Severity and priority assignment
- Defect retesting
- Defect closure

## Sample Defect Areas

- Customer profile validation
- Customer search
- Account information
- Data consistency
- Transaction processing
- Negative scenarios

## Tools

- JIRA
- Confluence
- Test Management tools

> Note: All defects and data in this portfolio are fictional and created for demonstration purposes.
